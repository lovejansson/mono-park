# Mono park

A pixel art sim intended to be put up as a digital artwork on the wall. It simulates a quiet day at the park, created using a Solero Shots-inspired color palette and a 16×16 pixel art style.
The artwork is rendered at 640×360 pixels and scales to 16:9 resolutions using integer scaling, preserving the original pixel art without distortion.

## Tech stack

[pim-art template](https://github.com/lovejansson/pim-art)
[Typescript](https://www.typescriptlang.org/)
[Vite](https://vite.dev/)
[Tauri](https://v2.tauri.app/)
